## 2025-05-18 - Async Directory Listing
**Learning:** Synchronous directory listing via `Directory.listSync()` in Dart can block the UI/isolate thread significantly when checking directories with a large number of files. Converting it to `Directory.list()` utilizing `await for` substantially reduces execution time (e.g. from ~2000ms to ~969ms in our test with 5000 files) and avoids blocking the main thread.
**Action:** When scanning or iterating over directories, especially if it may happen on the UI thread or as part of a high-load library scan, always prefer asynchronous file system operations.
