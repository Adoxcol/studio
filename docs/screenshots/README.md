# Screenshots

Drop app screenshots into this folder, then reference them in the root `README.md`.

## Naming convention

| File | Contents |
|------|----------|
| `library.png` | Main library view — track list / album grid |
| `playback-mode.png` | Full-screen Playback Mode with artwork background |
| `now-playing.png` | Now Playing panel with spectrum visualizer |
| `metadata-editor.png` | Metadata editor with preview |
| `smart-playlist.png` | Smart playlist rule builder |
| `equalizer.png` | ISO 10-band graphic equalizer |
| `queue.png` | Queue / history panel |
| `settings.png` | Settings page (theme / appearance) |

## Guidelines

- **Format:** PNG preferred; JPEG acceptable for photographs.
- **Resolution:** Capture at 1× (native pixels). 1280 × 800 or wider works well.
- **Window chrome:** Include the custom titlebar so the frameless shell is visible.
- **Theme:** Dark theme screenshots for the primary slots; add light-theme
  variants as `*-light.png` if you want them.
- **No PII:** Clear your library of real track data before capturing, or blur
  artist/album names in post.

## After adding screenshots

Update the `## Screenshots` section in `README.md` — replace each placeholder
comment with a real `![alt](docs/screenshots/<file>.png)` line.
